# 活动题卡核验范围

当前显示与输入权威是[对话输入就绪](composer-input.md)。活动题卡只在消息列表
中出现一张，与历史共用滚动区；CHECK 菜单与可回答 hook 问卷统一选择并去重。
启动阶段没有原生历史时也使用同一消息滚动区。题干去除终端左边框；命令、路径、
选项范围不因去重改变。草稿、实例校验、菜单按键与用户主动切换终端的行为保留。

[题卡浏览器](../tests/question_browser.py)覆盖长中文题干、逐行边框、选项说明、
原生历史与迟到 hook，实际滚动、填写并回答；核对原生答案、单卡、输入区高度、
无第二滚动区及草稿保留。受影响的启动 trust、各 CLI 菜单与历史另选对应回归。
具体视口和主题按变更选择并检查完整页面；此索引不宣称某次执行或部署已通过。
