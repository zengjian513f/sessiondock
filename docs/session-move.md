# 选择会话并跨机迁移

迁移只移动用户选择的会话，原生 SID、rollout ID 和历史中的身份引用保持不变。
当前原生适配支持 Claude、Codex、Grok、Droid；Kiro、Agy、OpenCode、CodeBuddy 尚不支持。
页面和新计划不提供复制、同机克隆或生成新身份。已有事务仍按原记录恢复，见
[事务与恢复](session-clone.md)。本功能是用户明确要求的新功能，不受 Python 功能对齐范围限制。

## 页面

“迁移会话树”从所选会话读取关系树，按树状结构显示所有已知成员。默认选中源机器上
支持且已停止的会话；不支持的来源、运行中会话和位于其他机器的成员显示灰色复选框及原因。
其他机器的成员用于保留完整归属上下文；它们从各自所在机器另行迁移。
父子复选框独立，取消父会话不自动取消独立的子会话。全选框只控制可迁移成员并显示半选状态。

目标机器只能选另一台在线且启用的机器。没有选择会话、目标无效、预检未完成或失败时
不能确认。目标机器、勾选集合和原生依赖必须与最终预检一致；执行或结果不确定时锁定选择，
重试沿用同一事务，不能重新分配身份。取消预览不移动原生历史。

### 操作与身份选项

只有“迁移所选会话”一种操作。没有复制切换或新 ID 开关。
原生身份固定，Hub UID 的机器部分随归属位置变化；旧会话链接沿迁移账本解析到新位置。
成功后打开本次实际迁移的一个目标会话，即使打开对话框的根会话未被选中。

## 操作单元：整个连通组

DELTA：连通组只用于发现候选树，不再要求搬走所有逻辑亲属。
`nest_parent`、自包含 fork 和 continuation 可以跨越本次选择边界。它们不强制父、子或兄弟
一起迁移。已知但缺失的显示父关系保留原描述，不串到另一节点的同 SID 会话。

原生物理历史依赖不能拆断：同线程多代 rollout、`history_base` 固定前缀、原生子代理及
必须存在的 agent 工具引用形成联动单元。选择或取消其中一项会同步该单元的复选框。
后端复核同一依赖闭包；预览后新增依赖时要求重新读取树，不暗中扩大已确认的选择。
不支持来源不会被联动变成可选，也不能把其镜像当原生会话发布。

索引使用同一份 inventory 快照，区分原生逻辑关系和物理历史依赖。首次请求完成关系发现，
后续复用按文件 stamp 失效的关系摘要；不为迁移定时扫描所有历史，不在复制文件时持有列表锁。

## 每个会话的原生文件集

| 来源 | 迁移内容 | 不迁移 |
| --- | --- | --- |
| Claude | transcript、所属 subagents、tool-results、sidecar；存在的 file-history | 进程、PTY、临时后台任务日志 |
| Codex | 所选线程的全部代次、归档及固定前缀依赖；当前 rollout 选择和原生数据库投影 | 进程、队列、内存工具句柄 |
| Grok | 完整会话目录、summary、chat/update、checkpoints 及子代理元数据 | 进程和运行中执行状态 |
| Droid | JSONL、同名 settings、会话快照 manifest 和有效边界引用的内容文件 | 进程、认证、共享快照库中其他会话的数据 |

迁移原生文件遵守最小改动原则；固定身份时保留原历史，不重排 JSON、改写用户正文或
重新序列化整条记录。目录中必要的附件、外部结果引用和原生 schema 仍按适配器核对。
Codex 导入包括原生名称、归档/置顶/项目、动态工具定义、goal、目标续接延迟、附件关联及
实时历史投影。只导入所选线程及必需关联，不覆盖整库；不复制认证凭据、运行任务或实时连接。

## 前置条件与拒绝条件

只检查实际选择及其原生依赖。源和目标必须在线、具备迁移服务、Linux 平台、配置兼容的
CLI 根与原生 schema；源配置回收站，移动两端不能共用同一份 CLI 存储。
所选会话停止写入，工作目录及历史明确引用的外部依赖在目标可用。

Codex 停止 SDK 的回执不等于原生线程已卸载；预检查 daemon loaded 状态。
仍加载时提示等待卸载或关闭其他连接，不能把此状态说成模型仍在执行。
停写观察覆盖实际原生成员，包括侧栏顶层列表中隐藏的子代理。迁移树直接显示写入者
及其不可拆分依赖的不可选状态；计划和执行阶段仍重新核对，不能以父会话已停止代替子代理检查。
未选中的运行会话和不支持来源不阻止迁移，除非它们是不可拆分的原生依赖。

### 工作目录一致性的验证范围

两端 CLI 根和工作目录使用相同绝对路径；不复制工作目录、不创建 Git worktree，也不扫描
或比较整个工作区。仅验证历史明确引用的图片、附件、输出文件和链接内容，以及目录存在性。
CLI 版本和动态工具执行器核验结果作为可见提示，缺少版本信息不能假称能够原生继续。

目标不存在原身份时正常发布。相同历史可复用；可验证的固定前缀允许延长。
不同分支、当前 rollout 冲突、其他目标内容或被并发修改的显示设置不覆盖，保留现场并报错。
源历史、原生元数据和已确认选择在执行前、交接前及清理前复核。

### Droid 文件回退快照

DELTA：Droid 的 `.factory/snapshots` 使用会话专属 manifest 和共享内容库。
本次确认的文件集为 transcript、settings、snapshot manifest 及其有效内容。
`decompMissionId` 或设置标签中的 mission 指针尚无完整持久状态适配，明确拒绝迁移；
不将日志、缓存或未知 mission 根盲目纳入。
移动保留 transcript、settings、manifest 原字节和所有原生身份；目标按有效边界合并
`.index.json` 与 `content/.metadata.json` 的引用计数，只修改必要字段和插入项，保留其他
会话及未知字段。共享 JSON 与历史文件一起持久发布，失败通过同一事务回滚。

原生进程会缓存这些共享 JSON，故带快照的目标预检和发布前均要求该 Droid 根没有
存活写者；不主动停止其他会话。受管 SDK 启动与快照发布使用同一锁；外部 TUI 仍按
既有停写观察合同核验，不宣称能围栏独立 CLI。源端只移走专属 manifest、历史及设置，
不删除共享内容，也不改写运行中其他会话缓存的全局索引。源端旧队列和引用计数交由
原生后续淘汰处理；回迁可复用尚存的相同边界和内容。已有共享内容或索引却缺少引用计数时，迁移提示先由 Droid 完成原生恢复，不清空无关队列；真正空根可以初始化共享元数据。新建复制仍保持全局关闭。

## SessionDock 自身状态

迁移保留所选会话的星标、分组、父会话可见性和用户明确的附属/解除决定。
`nest_parent` 的源机器含义必须转换成目标机器上的明确含义：

- 父子一起迁移时，目标端仍为本机父子关系。
- 只迁移子会话时，目标子会话指向原机器上的父会话。
- 只迁移父会话时，源端留下的子会话改指目标机器；不支持来源也保留这个父关系。
- 父会话回迁时，本机现有子会话重新指回本机；仍在其他机器的子会话保留跨机父关系。

其他节点保存的父身份由 Hub 按已完成的移动记录解析当前位置，列表、搜索、详情及实时
元数据使用同一规则。离线子节点回归和 Hub 重启仍能恢复结构；不能仅按相同 SID 合并机器。
手动解除关系不被迁移补成新关系。用户工作关系、草稿和运行绑定不自动变成新的原生亲属。

### 当前移动交接与清理

源端 journal 固定选择、原生身份、源/目标节点和显示元数据，预览不暂存全量历史。
执行时源端复核并保留导出租约，私有暂存按原身份传输；目标先验证、发布并保持执行围栏。
源持久化不可逆的归属切换后，清理本次所选历史和原生数据库记录，再允许目标继续执行。
留下的显示子关系转换为跨机描述；真正的新物理引用仍阻止删除被引用历史。

交接前失败可以撤回目标发布，源历史保留；交接后只继续同一事务的清理和激活，不回到旧执行归属。
源端清理失败报告待重试，目标完整历史和围栏保留。原生数据库、文件、显示元数据分别保存补偿记录，
重试不覆盖并发内容。终态先持久化，再清理私有暂存并精简账本；精简失败不把成功迁移改报失败。

### 发布校验范围

验证本次实际迁移的所有会话及其原生依赖，允许多条独立分支同时选择。
显示父会话可以在选择之外或其他节点；物理依赖仍须完整。验证 SID、当前历史、文件、
数据库投影和关系，不以按钮可点、传输完成或摘要通过代替原生完整性。

## 当前接口

保留既有 URL 名称以恢复已有账本；名称中的 `clone` 不再表示允许新建复制操作。

- `POST /api/session/transfer/tree {uid}`：读取树、可选状态、原生联动 UID；不创建迁移事务。
- `POST /api/session/clone/plan {uid, target_node, selected_uids, mode:"move", new_ids:false}`：
  固定实际选择并预检。省略选择时默认源端支持成员；空选择报错。新建复制或新身份请求被拒绝。
- `POST /api/session/transfer/clone {uid, target_node, operation_id, mode:"move", new_ids:false}`：Hub 执行已确认事务。
- `POST /api/session/clone/progress`、`/api/session/transfer/progress`：读取节点或 Hub 进度。
- `POST /api/session/clone/cancel`、`/api/session/transfer/cancel`：取消预览或按交接阶段撤回/继续恢复。
- `GET /api/session/transfers`：未完成事务；客户端关闭后由服务端继续恢复。

入口沿用 `session_clone_local_codex` 的历史能力名，跨机移动使用 `session_move_remote`；
Hub 不再声明跨机复制可用。传输和交接控制端点只开放给认证节点通道，见
[传输层](session-transport.md)及[路由](route-ledger.md)。

## 验证

[选择迁移浏览器套件](../tests/session_selected_move_browser.py)使用三节点 Hub 与两台机器的私有目录，
实际点击树、改变选择、迁移及回迁，检查灰色来源、原生依赖联动、固定 ID、留下的跨机父子关系、
第三节点同 SID 隔离和 Hub/节点重启。它不调用真实模型，也不操作生产会话。

[Agy 历史套件](../tests/agy_history_browser.py)验证不支持来源保持原生数据及可见不可选状态。

[Droid 移动浏览器套件](../tests/droid_move_browser.py)通过私有 SSH 节点覆盖设置、文件回退快照、共享内容及回迁。
