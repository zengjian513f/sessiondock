## 修复与实验覆盖

本次修复不解析历史命令来猜测当前归属，也不把侧栏嵌套当作因果关系。
本机启动边以被启动 CLI 的完整进程实例为键，记录其实际 spawner；沿进程祖先
传播到工作进程及后续 SSH 启动，保留已确认后代的链。独立恢复同一原生会话
的另一个实例不会被会话级递归误算到启动者。

实际进程实验一度出现 fork 证据存在但一个脱离工作进程未归属，复跑成功。
检查发现即时 `fork()` 继承依赖父绑定已经存在，且尚未进入快照的中间进程可能
在刷新时失去绑定。修复增加沿保留的完整 fork 实例图重新查找已确认祖先；
保留共享连接/共享祖先边界，PID 复用不能沿旧图找回身份。
确定性浏览器夹具覆盖“父进程已退出、fork 图先于归属、环境没有身份”场景。

| 启动方式 | 实验与结果边界 |
| --- | --- |
| 普通子进程、后台 shell、`nohup`、`setsid` | 真实 Python 假工作进程，实际内核 fork/exit 事件；会话归属及退出后的浏览器计数可检查 |
| 双重 fork、`Popen(start_new_session=True, env={})`、清空环境 | 真实脱离进程；必须有可追溯的事件或已确认进程证据，不能仅凭进程名找会话 |
| multiprocessing spawn | 真实多层启动，工作进程归属；它验证进程机制，不等于对所有第三方分布式框架背书 |
| 本机子 CLI、孙 CLI、生成/预处理工作进程 | 私有进程树 + 真实 collector/HTTP/Chromium；检查 inclusive 并集、GPU 去重、direct 隔离和独立 resume 排除 |
| 短命 SSH、延迟远端孙进程 | 私有 loopback sshd，真实 IPv4/IPv6 连接、双重 fork、collector/Hub 重启；客户端不必活到轮询 |
| SSH ControlMaster/ControlPersist | 真实复用连接实验；共享通道不归给主连接拥有者，仍是归属缺口 |
| 已存在的共享 tmux server | 私有真实 tmux socket；没有每作业身份时不归属，不把发出 tmux 命令当作子进程祖先 |
| systemd 委托启动 | 临时私有单元；无每作业身份时不归属。显式提供会话身份的 tmux/systemd 作业另作正向对照 |
| `timeout`、taskset、numactl 等执行包装 | 不改变父子进程或继承环境时沿相同证据链处理；没有逐个实测全部包装组合 |
| 容器、队列调度器、常驻 RPC 服务、其他 UID | 普通进程图不能证明请求者；历史命中不是实际成功启动证据，本次未取得全面的隔离运行证明，不能宣称覆盖 |

真实内核实验使用临时 sshd/密钥、私有 tmux socket、临时 systemd 单元和只暴露
测试 PID 的进程视图。只停止实验自己创建的进程，不使用生产会话作夹具。
GPU 回归注入私有测量值，因为真实采集器对合成 proc 根禁用 NVIDIA 查询；
它验证归属、聚合、释放和浏览器展示，不声称在真实 GPU 上执行了训练。

## 资源释放能检测什么

- **进程退出**：生命周期事件去掉绑定，后续进程快照/样本按 PID + start ticks
  排除死进程；僵尸不算运行进程。子进程仍活着时不会因 CLI 已结束而清空它。
  真实进程实验检查浏览器计数回到基线。
- **PID 复用**：绑定、fork 图、GPU/PSS 样本使用完整实例；浏览器夹具检查复用
  PID 不恢复旧归属和旧资源。
- **GPU 上下文释放但进程仍在**：依赖下一次 NVIDIA compute-process 观测，约
  10 秒刷新；超过 30 秒或查询失败应为 unavailable，不强写 0。浏览器夹具模拟
  上下文释放，证明存活 CLI 不会把已释放 GPU 固定为占用。
- **CPU、PSS 与存储**：CPU/proc storage 约 2 秒，PSS 目标约 30 秒且最多缓存
  60 秒；页面与 Hub 轮询还会增加可见延迟。PSS 降低不等于系统文件缓存已回收，
  分配器保留内存也不等于仍在执行任务。
- **逻辑作业完成、租约释放、文件锁、端口、后台守护进程内的请求完成**：不是
  进程退出协议。用户回复“完成”、返回码、调度器释放租约不能证明资源已归零；
  SessionDock 不解析业务账本来代替 OS/NVIDIA 观测，也不替作业杀进程释放资源。
- **短命任务和采集停机**：实时采样不是完整累计计费；已丢失的历史启动不能
  从自然语言恢复。未归属 GPU 会标注覆盖不完整，不能把已确认小计当全量。
